# Bank Management System - Java

Hey there!  

This is a simple console-based Bank Management System I built using Java to practice core Object-Oriented Programming (OOP) concepts.

## What this project does
- Manages basic bank accounts (Savings Account)
- Lets you check account balance safely
- Handles simple transactions like depositing and withdrawing money

## OOP Concepts I used here
- **Encapsulation:** Used private variables with getters and setters to keep balance details secure.
- **Inheritance:** The `SavingsAccount` class extends the `BankAccount` class.
- **Abstraction:** Created a `Transaction` interface and a `BankAccount` abstract class to structure the logic.
- **Polymorphism:** Overrode the deposit and withdraw methods in the savings account class.

## How to test it
1. Copy the code from `Main.java`.
2. Paste it into OnlineGDB, Programiz, or any Java IDE (Eclipse / IntelliJ / VS Code).
3. Run the program to see how it works!
